# TCS-iON-HR-Analytics-Project
An interactive Power BI dashboard developed during the TCS iON Industry Project to analyze factors contributing to employee attrition and optimize performance management using HR analytics.

Employee Attrition and Performance Analysis
TCS iON Industry Project
## Project Objective
The goal of this project is to provide actionable insights into HR analytics, focusing on employee turnover patterns and performance optimization.  
## Tech Stack
Data Tool: Microsoft Power BI
Processing: Power Query (ETL)
Logic: DAX (Data Analysis Expressions)
## Key Features
Executive Overview: KPI cards for Headcount, Attrition Rate, and Avg Salary.
Demographic Analysis: Visualizing trends by Age, Gender, and Marital Status.
Performance Metrics: Correlation between income levels and performance ratings.
